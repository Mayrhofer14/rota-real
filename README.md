# Rota Real

Jogo de corrida 3D no navegador. Escolha largada e chegada como num app de mapas (ou um circuito de Fórmula 1 / Fórmula Indy) e corra sobre fotos de satélite, com relevo real.

Jogar: https://mayrhofer14.github.io/rota-real/

## Créditos de dados

- Imagens de satélite e mapa de ruas: Esri, Maxar, Earthstar Geographics
- Ruas, prédios e nomes: © OpenStreetMap (ODbL), via OpenFreeMap / OpenMapTiles
- Rotas: OSRM · Busca de endereços: Photon (Komoot) / Nominatim
- Relevo: Terrain Tiles (AWS Open Data, Mapzen)
- Traçados de Fórmula 1: [bacinger/f1-circuits](https://github.com/bacinger/f1-circuits) (MIT)
- Traçados de Fórmula Indy: extraídos do OpenStreetMap (ODbL)
